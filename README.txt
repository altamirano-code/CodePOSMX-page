CodePOS MX — Sitio web

Contenido:
- index.html: página principal completa (HTML, CSS y JavaScript integrados).
- README.txt: instrucciones para probar y publicar el sitio.

Para probar:
1. Extrae el ZIP.
2. Abre index.html en tu navegador.

Para publicar en GitHub Pages:
1. Crea o abre un repositorio.
2. Sube index.html a la raíz del repositorio.
3. En Settings > Pages, configura la rama principal y la carpeta raíz.

Nota: Poppins se carga desde Google Fonts y requiere conexión a internet.
Los enlaces de correo, Instagram y Facebook están configurados en la página.
